# DJIsaacVies Producciones

Sitio web diseñado para promocionar y contratar servicios de:

- DJ Profesional
- Sonido para eventos
- Iluminación profesional
- Animación de fiestas y eventos musicales

## Tecnologías utilizadas

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Formspree

## Características principales

- Diseño responsivo
- Navegación interna
- Cards de servicios
- Sección de reseñas con Grid
- Formulario funcional con Formspree
- Integración multimedia
